## Q03_57 Instructions 
Write a program that reads three integer values from the keyboard representing, respectively, a number of quarters, dimes, and nickels.  Convert the total coin amount to dollars and output the result with a dollar notation.  
### Q03_57 Test 1 - Only Quarters
**Input:**  
5  
0  
0  
**Output:**  
The amount is $1.25  
### Q03_57 Test 2 - Only Dimes
**Input:**  
0  
15  
0  
**Output:**  
The amount is $1.50  
### Q03_57 Test 3 - Only Nickels
**Input:**  
0  
0  
40  
**Output:**  
The amount is $2.00  
### Q03_57 Test 4 - All Coins
**Input:**  
10  
25  
10  
**Output:**  
The amount is $5.50    
## Q03_63 Instructions  
Write a program that reads two numbers from the keyboard representing, respectively, an investment and an interest rate (you will expect the user to enter a number such as .065 for the interest rate, representing a 6.5% interest rate).  Your program should calculate and output (in \$ notation) the future value of the investment in 5, 10 and 20 years using the following formula:  
$ futureValue = investment*(1+interestRate)^{year} $  
Assume the interest rate is an annual rate and is compouned annually.  
### Q03_63 Test 1 - No Interest At All!
**Input:**  
500  
0     
**Output:**  
With an investment of $500.00  
at an interest rate of 0.00% compounded annually:  
the future value in 5 years is $500.00  
the future value in 10 years is $500.00  
the future value in 20 years is $500.00   
### Q03_63 Test 2 - With Interest
**Input:**  
500  
.045  
**Output:**  
With an investment of $500.00  
at an interest rate of 4.50% compounded annually:  
the future value in 5 years is $623.09  
the future value in 10 years is $776.48  
the future value in 20 years is $1,205.86
